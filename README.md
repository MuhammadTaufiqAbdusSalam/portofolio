## 🚀 Deployment

This site is automatically deployed to Vercel on every push to `main` branch.

### Local Development

Simply open `index.html` in your browser, or use a local server:

```bash
# Using Python
python -m http.server 8080

# Using Node.js live-server
npx live-server
```

### Deploy to Vercel

1. Push code to GitHub
2. Import repo at [vercel.com/new](https://vercel.com/new)
3. Vercel auto-detects static site - no config needed
4. Done! 🎉

## 🎨 Customization

Update the following in `index.html`:

| Section | What to Update |
|---------|---------------|
| `<title>` | Your name |
| Hero | Name, title, description, social links |
| About | Bio, location, email, tech tags |
| Skills | Skill names & percentages |
| Projects | Project info, links, screenshots |
| Experience | Work history & education |
| Contact | Email, WhatsApp, LinkedIn, GitHub |
| Footer | Social links |
